# Driver Monitoring System

This project detects driver fatigue and distracted driving using a Raspberry Pi 5 and a Raspberry Pi AI camera.

## Technologies
Python
Raspberry Pi
Computer Vision

## Overview
The system monitors facial landmarks and eye movement to detect signs of fatigue or distraction. 
When unsafe behavior is detected, the system records timestamps and safety events for review.

## Hardware
Raspberry Pi 5
Raspberry Pi AI Camera
